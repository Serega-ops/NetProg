# NetProg

Практическое задание 3 — сетевые клиенты.

## daytime
UDP-клиент службы Daytime (порт 13).

Сборка и запуск:
    cd daytime && make
    ./daytime_client 172.16.40.1

## echo
TCP-клиент службы Echo (порт 7).

Сборка и запуск:
    cd echo && make
    ./echo_client 172.16.40.1

## Тестирование
Оба клиента проверены на сервере кафедры 172.16.40.1:
- daytime вернул текущую дату/время сервера;
- echo вернул отправленную строку.
